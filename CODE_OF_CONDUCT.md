# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Standards

Be kind. Assume good intent. Disagree on technical merits. Cite sources.

## Reporting

Email the maintainers privately. Public callouts are a last resort.

## Enforcement

Maintainers reserve the right to remove comments, commits, code, issues, PRs, and contributors that violate this code.
