# Mini libsodium API Guide

Use this artifact when reviewing or writing code that does any of:
- Encrypts data with a symmetric key
- Generates or verifies a MAC
- Derives subkeys from a master key
- Hashes or verifies a password
- Encrypts a sequence of messages in a session

---

## Operation Selection Guide

| You want to... | Use | Production library |
|----------------|-----|--------------------|
| Encrypt + authenticate one message | **secretbox** | `nacl.secret.SecretBox` / `crypto_secretbox_easy` |
| Authenticate (no encryption) | **auth** | `nacl.auth` / HMAC-SHA256 |
| Derive multiple subkeys from a master | **kdf_derive_from_key** | `crypto_kdf_derive_from_key` / HKDF |
| Turn a password into a key | **pwhash** | `nacl.pwhash.argon2id` / `crypto_pwhash` |
| Encrypt a sequence of chunks | **secretstream** | `crypto_secretstream_xchacha20poly1305_*` |

**Never use**: raw ChaCha20 without Poly1305, raw AES-CTR without a MAC, HMAC-MD5, ECB mode, or any manual nonce construction.

---

## Threat Model Summary

| Operation | Protects against | Does NOT protect against |
|-----------|-----------------|--------------------------|
| secretbox | Eavesdropping, ciphertext tampering, wrong AAD | Replay of the entire box (add sequence numbers if needed) |
| auth | Message tampering, forgery without key | Replay of valid (message, tag) pairs |
| kdf | Key reuse across purposes | Weak master key (garbage in → garbage out) |
| pwhash | Offline brute-force, rainbow tables | Online guessing (use rate limiting separately) |
| secretstream | Chunk tampering, chunk reorder, chunk replay within session | Cross-session replay (bind header to session identity) |

## PR Review Checklist

### secretbox / secretbox_open

- [ ] **Key size**: key is exactly 32 bytes from `secretbox_keygen()` or equivalent CSPRNG.
- [ ] **Nonce**: nonce is not generated by the caller — the API generates it internally. If the caller passes a nonce, ensure it is never reused for the same key.
- [ ] **AAD**: all metadata that must be authenticated (record ID, version, endpoint) is included in `aad`. An empty `aad` is a conscious choice, not a default.
- [ ] **Error handling**: `secretbox_open` failure is handled as a hard error — no fallback decryption attempt, no silent discard.
- [ ] **Box format**: nonce + tag + ciphertext are kept together. Splitting them into separate fields risks misuse.

### auth / auth_verify

- [ ] **Constant-time verify**: comparison uses `hmac.compare_digest` or equivalent — not `==`, not `tag[:n] == expected[:n]`.
- [ ] **Key separation**: the auth key is not the same bytes as any encryption key.
- [ ] **MAC covers the right bytes**: the MAC input includes all fields that must be authentic (length prefixes, type tags, etc.), not just the payload.
- [ ] **Tag length**: a truncated tag is a documented protocol choice, not an accident. Minimum 16 bytes.

### kdf_derive_from_key

- [ ] **ctx is unique per module**: the 8-byte context label is documented and unique across all callers in the codebase. Two modules with the same ctx silently share key material.
- [ ] **subkey_id is documented**: the mapping from subkey_id → purpose is written down and stable. Changing the mapping silently derives a different key.
- [ ] **Master key is high-entropy**: the master key comes from `kdf_keygen()` or an ECDH/DH result, not a password. Passwords → `pwhash` first.
- [ ] **Subkey is not re-derived per request**: derive once at startup or session init and cache. Re-derivation is not expensive but re-using a cached value is cleaner.

### pwhash / pwhash_str

- [ ] **Salt is unique per password**: never reuse a salt across users or across registrations for the same user.
- [ ] **Salt is stored alongside the hash**: the output of `pwhash_str` is stored in full — salt + params + tag. Never store only the tag.
- [ ] **Work factor is explicit**: `opslimit` is a named constant, not a magic number. It is documented in terms of time on target hardware.
- [ ] **Work factor upgrade path exists**: there is a plan to re-hash passwords at login when the stored `opslimit` is below the current minimum.
- [ ] **Encoding is fixed**: passwords are encoded to bytes before hashing (always UTF-8). This is consistent across registration and login.
- [ ] **Prefer Argon2id in production**: PBKDF2 is not memory-hard. scrypt or Argon2id resist GPU/ASIC attacks better at the same user-visible latency.

### secretstream

- [ ] **Header is transmitted before any chunks**: the receiver must call `init_pull` with the header before processing any chunk.
- [ ] **Counter is never reset without a new session**: resetting the counter to 0 with the same key and base nonce breaks nonce uniqueness.
- [ ] **Authentication failure is fatal**: after any `secretstream_pull` raises, the session state is unusable. Start a new session.
- [ ] **AD covers session metadata**: if chunks belong to different logical streams, include a stream identifier in `ad`.
- [ ] **Counter overflow is handled**: for very long sessions (2^32 chunks), the 4-byte counter wraps. Use a session limit or a wider counter.

## Red Flags (immediate rejects in code review)

- `nonce = b"\x00" * 12` — hardcoded nonce is nonce reuse on every message.
- `if tag == expected:` — timing oracle; use `hmac.compare_digest`.
- `sha256(password)` as the key — SHA-256 is fast; this is no better than plaintext for guessing.
- `enc_key = mac_key = master` — key reuse; one key must never serve two roles.
- `aes_cbc(key, iv, data)` without a MAC — CBC without authentication gives no integrity.
- `tag = hmac(key, plaintext)` followed by `encrypt(plaintext)` — MAC-then-Encrypt is vulnerable to padding oracle attacks in CBC. Use Encrypt-then-MAC or AEAD.

## Production Library Quick Reference

```python
# PyNaCl — direct libsodium binding
from nacl.secret import SecretBox
from nacl.utils import random

key = random(SecretBox.KEY_SIZE)
box = SecretBox(key)
encrypted = box.encrypt(b"message")        # nonce embedded
decrypted = box.decrypt(encrypted)

# cryptography — ChaCha20Poly1305
from cryptography.hazmat.primitives.ciphers.aead import ChaCha20Poly1305
import os

key = ChaCha20Poly1305.generate_key()
chacha = ChaCha20Poly1305(key)
nonce = os.urandom(12)
ct = chacha.encrypt(nonce, b"message", b"aad")
pt = chacha.decrypt(nonce, ct, b"aad")

# cryptography — HKDF
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
from cryptography.hazmat.primitives import hashes

hkdf = HKDF(algorithm=hashes.SHA256(), length=32, salt=None, info=b"enc\x00\x00\x00\x00\x00")
subkey = hkdf.derive(master_key)

# cryptography — Argon2id (prefer over PBKDF2)
from cryptography.hazmat.primitives.kdf.argon2 import Argon2id

kdf = Argon2id(salt=salt, length=32, iterations=1, lanes=4, memory_cost=65536)
key = kdf.derive(password)
```
