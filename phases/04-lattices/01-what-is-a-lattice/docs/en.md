# What Is a Lattice — Geometry of Z^n

> A lattice is every integer combination of a basis — the “grid” is not unique, the set is.

**Type:** Learn
**Languages:** Python
**Prerequisites:** Comfort with vectors, dot products, determinants
**Time:** ~45 minutes

> ⚠️ Educational implementation. Not constant-time. Not production-safe.

## Learning Objectives

- Explain why a lattice is defined as a set of integer combinations rather than as a fixed basis
- Identify which quantities are lattice invariants (determinant, successive minima) versus basis-dependent properties
- Compute lattice points from a 2D integer basis using linear combinations of basis vectors
- Distinguish between different bases that generate the same lattice via unimodular transformations
- Apply a unimodular basis change and verify that the fundamental parallelepiped volume is preserved

## The Problem

Post-quantum cryptography is, in practice, mostly lattice cryptography: LWE / Ring-LWE, NTRU, Dilithium, Kyber, and a long list of “noisy linear equations” whose security is explained using lattices.

But “lattice” is one of those words people nod at while holding the wrong mental model. Many learners hear “a grid” and assume:

- the basis vectors *are* the lattice (they aren’t)
- the spacing between grid lines is an intrinsic parameter (it isn’t)
- a lattice has “the basis” (it doesn’t — there are infinitely many)

If you don’t fix this early, later lessons (determinant, successive minima, SVP/CVP, LLL) feel like magic. This lesson gives you the one definition that makes the rest of lattice crypto readable.

## The Concept

### Definition: integer combinations of a basis

In `R^m`, pick `n` linearly independent vectors `b1, ..., bn`. Stack them as columns of a matrix `B ∈ R^{m×n}`.

The lattice generated by `B` is:

```text
L(B) = { B z : z ∈ Z^n }.
```

If `m = n` and `B` is full-rank, you get a full-rank lattice in `R^n`. (Later we’ll use *module* and *ideal* lattices, but the same definition “integer combinations” stays true.)

### The “grid” picture (2D)

Take two basis vectors `b1`, `b2` in `R^2`. Every integer pair `(z1, z2)` gives a point:

```text
v = z1*b1 + z2*b2
```

ASCII intuition (sheared grid):

```text
b2 ^
   |
   |     •      •
   |  •      •
   |     •      •
   +-----------------> b1
```

The important part: you should think of the *set of points* as the lattice, not the basis arrows.

### A lattice does not have a unique basis

If `U` is an integer matrix with determinant `±1` (a **unimodular** matrix), then `U` maps `Z^n` to `Z^n` bijectively. That implies:

```text
L(B) = L(BU).
```

So `B` and `B' = B U` are different bases for the same lattice. This is why “the basis length” is not a property of the lattice. The lattice has geometric invariants (determinant, successive minima, covering radius, …), but a basis is a coordinate system you chose.

### Fundamental parallelepiped and determinant (preview)

In full rank `R^n`, the parallelepiped spanned by a basis is:

```text
P(B) = { B x : x ∈ [0,1)^n }.
```

Its volume is `|det(B)|`. That value depends only on the lattice (not on the chosen basis), and we’ll call it the **determinant** of the lattice:

```text
det(L) = |det(B)|.
```

This is the first invariant you should internalize: basis changes with `det(U)=±1` keep `|det(B)|` unchanged.

## Build It

We’ll build a tiny “lattice sandbox” for 2D: generate lattice points, change bases without changing the lattice, and brute-force a shortest lattice vector in a bounded window. This is not an efficient SVP solver — it’s a microscope for intuition.

### Step 1: Represent a 2D integer basis

We represent a basis as two integer vectors `b1=(x1,y1)`, `b2=(x2,y2)`:

```python
Basis2D = tuple[tuple[int, int], tuple[int, int]]  # (b1, b2)
```

Compute a lattice point from integer coefficients:

```python
def lattice_point_2d(basis: Basis2D, z1: int, z2: int) -> tuple[int, int]:
    (x1, y1), (x2, y2) = basis
    return (z1 * x1 + z2 * x2, z1 * y1 + z2 * y2)
```

### Step 2: Enumerate lattice points in a box

To “see” a lattice, enumerate small integer coefficients and keep the points that land in a bounding box:

```python
def lattice_points_in_box_2d(
    basis: Basis2D,
    coeff_bound: int,
    x_min: int,
    x_max: int,
    y_min: int,
    y_max: int,
) -> list[tuple[int, int]]:
    points: set[tuple[int, int]] = set()
    for z1 in range(-coeff_bound, coeff_bound + 1):
        for z2 in range(-coeff_bound, coeff_bound + 1):
            x, y = lattice_point_2d(basis, z1, z2)
            if x_min <= x <= x_max and y_min <= y <= y_max:
                points.add((x, y))
    return sorted(points)
```

### Step 3: Determinant (2D area)

In 2D, the determinant is the signed area of the parallelogram spanned by `(b1, b2)`:

```python
def det_2d(basis: Basis2D) -> int:
    (x1, y1), (x2, y2) = basis
    return x1 * y2 - y1 * x2
```

### Step 4: Change basis with a unimodular matrix

Pick a unimodular integer matrix:

```text
U = [[a, b],
     [c, d]]   with det(U)=a*d-b*c = ±1
```

Then `B' = B U` is a different basis of the same lattice. For column-basis convention, this yields:

```python
def change_basis_unimodular_2d(
    basis: Basis2D, U: tuple[tuple[int, int], tuple[int, int]]
) -> Basis2D:
    (b11, b12), (b21, b22) = basis
    (a, b), (c, d) = U
    new_b1 = (a * b11 + c * b21, a * b12 + c * b22)
    new_b2 = (b * b11 + d * b21, b * b12 + d * b22)
    return (new_b1, new_b2)
```

### Step 5: Brute-force a “short vector” (toy SVP microscope)

Even in 2D, the shortest non-zero lattice vector is a geometric property of the lattice. A basis can hide it or reveal it, but cannot change it.

```python
def shortest_vector_bruteforce_2d(basis: Basis2D, coeff_bound: int) -> tuple[int, int]:
    best = None
    best_norm2 = None
    for z1 in range(-coeff_bound, coeff_bound + 1):
        for z2 in range(-coeff_bound, coeff_bound + 1):
            if z1 == 0 and z2 == 0:
                continue
            x, y = lattice_point_2d(basis, z1, z2)
            n2 = x * x + y * y
            if best_norm2 is None or n2 < best_norm2:
                best_norm2 = n2
                best = (x, y)
    if best is None:
        raise ValueError("no non-zero vectors in the given coefficient window")
    return best
```

## Use It

Real lattice work uses serious integer linear algebra. A common “practical lattice toolbox” in Python is `fpylll` (which wraps efficient libraries in C++).

Example: represent a basis as an integer matrix and run LLL reduction:

```python
from fpylll import IntegerMatrix, LLL

B = IntegerMatrix.from_matrix([[2, 1],
                               [0, 1]])  # row-major
LLL.reduction(B)
print(B)
```

We won’t lean on `fpylll` for understanding — we’ll build key pieces from scratch in later lessons — but it’s a good sanity-check tool when you start experimenting with real parameter sizes.

## Attack It

**Attack the wrong mental model:** “If I publish a basis with long vectors, my lattice is sparse and therefore hard.”

False. You can take a lattice with a short vector, apply a unimodular basis change that makes the basis vectors look huge, and the lattice still contains the same short vector (same point set).

This matters in crypto because “security” comes from the hardness of problems like SVP/CVP on a lattice *given a basis*, not from superficial properties of one particular basis presentation. Later, trapdoors will be “special bases” that make problems easy for the holder — and hard for everyone else.

## Exercises

1. Easy: Pick `b1=(3,0)`, `b2=(1,2)`. List 10 lattice points with small coefficients. What changes if you swap the order of `b1` and `b2`?
2. Medium: Find a unimodular `U` (det = ±1) such that `B' = B U` has a “nicer-looking” basis for the same lattice (try making one basis vector shorter).
3. Hard: For a random 2D basis with determinant `Δ`, brute-force the shortest vector in the window `[-k,k]^2` for increasing `k`. When does it stabilize? Why does this fail spectacularly in higher dimensions?

## Key Terms

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| lattice | “a grid” | the set of all integer combinations of a basis |
| basis | “the lattice vectors” | any generating set of linearly independent vectors whose integer span is the lattice |
| rank | “the dimension” | number of basis vectors (`n` in `L ⊆ R^m`) |
| unimodular matrix | “an invertible integer matrix” | integer matrix with determinant `±1` (inverse is also integer) |
| fundamental parallelepiped | “the unit cell” | `P(B) = B[0,1)^n`, a tiling cell for the lattice |
| determinant | “det(B)” | the lattice volume invariant `det(L)=|det(B)|` |
