## The Problem

A hardware wallet holding a single private key is a single point of failure. Steal the device, extract the seed, sign anything. Enterprises, custodians, and multi-party wallets all face the same question: how do you distribute the signing authority so that no one party can unilaterally spend funds, yet a sufficient quorum can always sign?

Naive multi-signature schemes still require each signer to hold a full private key and produce separate signatures that are combined on-chain, costing extra bytes and revealing the participant structure. **Threshold signatures** go further: the group generates a single key and produces a single signature indistinguishable from one generated by a single signer, yet the underlying secret is never held by anyone.

The building blocks are Shamir Secret Sharing (split a secret into shares, reconstruct from any t of n), Distributed Key Generation (generate shares without a trusted dealer), and threshold Schnorr signing (each party contributes a partial signature; the aggregated result is a standard Schnorr signature).

## The Concept

### Two primes, two roles

This implementation uses a Mersenne prime `N = 2^31 - 1` in two distinct roles:

| Role | Prime used | Why |
|---|---|---|
| Shamir polynomial field | `N` (prime) | Lagrange interpolation requires a prime field GF(p) |
| Group for DH/Schnorr | `N` (prime) | Elements of Z_N* (multiplicative group mod N) |
| Scalar exponents | `ORDER = N-1` | Fermat: `g^a ≡ g^(a mod (N-1)) mod N` for prime N |

**Critical distinction:** `ORDER = N - 1` is **not** prime (it factors as `2 · 3² · 7 · 11 · 31 · 151 · 331`). This means Lagrange interpolation for Shamir MUST use `N`, not `ORDER`. Scalar responses in Schnorr use `ORDER`. Using the wrong prime silently corrupts results.

### Shamir Secret Sharing

A degree-(t−1) polynomial `f` over GF(p) is constructed with `f(0) = secret`. Each party i receives the share `f(i)`. Any t points uniquely determine the polynomial (and thus `f(0)`); fewer than t points give no information about `f(0)`.

Reconstruction uses Lagrange interpolation at x=0:

```
f(0) = Σ_i  y_i · Π_{j≠i} (0 − x_j) / (x_i − x_j)   (mod p)
```

### Distributed Key Generation

In Pedersen DKG, each of the n parties:
1. **Round 1:** Chooses a random polynomial `f_i` of degree t−1, broadcasts `G^{f_i(0)}, G^{f_i(1)}, ...` (commitments), and sends `f_i(j)` secretly to party j.
2. **Round 2:** Party j sums all received shares: `sk_j = Σ_i f_i(j) mod ORDER`.

The **group public key** is `G^{f(0)} = Π_i G^{f_i(0)}` (product of all constant-term commitments). No single party ever knows `f(0) = Σ_i f_i(0)`.

### Threshold Schnorr (simplified FROST)

Each signer contributes to a joint Schnorr signature:

| Round | Signer | Broadcast |
|---|---|---|
| 1 | Pick nonce `k_i`; compute `R_i = G^{k_i}` | `R_i` |
| — | Aggregate nonce: `R = Π R_i` | — |
| 2 | Compute challenge `e = H(R ‖ msg)`; respond `s_i = k_i + sk_i · e` | `s_i` |
| — | Aggregate: `s = Σ s_i mod ORDER` | `(R, s)` |

Verification: `G^s = R · PK^e mod N` where `PK = Π G^{sk_i}`.

## Build It

### Step 1: Deterministic coefficients and helpers

```python
_TW_N: int = 2**31 - 1       # Field prime (Mersenne)
_TW_G: int = 3                # Generator of Z_N*
_TW_ORDER: int = _TW_N - 1   # Group order (Fermat)

def _det_coeff(seed: int, index: int, prime: int) -> int:
    """Deterministic polynomial coefficient from seed and index."""
    return _sha256_int(f"{seed}:{index}".encode()) % prime
```

### Step 2: Shamir Secret Sharing

```python
def shamir_split(secret: int, t: int, n: int, prime: int) -> list[tuple[int, int]]:
    coeffs = [secret % prime]
    for i in range(1, t):
        coeffs.append(_det_coeff(secret, i, prime))
    shares = []
    for x in range(1, n + 1):
        y = sum(coeff * pow(x, power, prime) for power, coeff in enumerate(coeffs)) % prime
        shares.append((x, y))
    return shares

def shamir_reconstruct(shares: list[tuple[int, int]], prime: int) -> int:
    secret = 0
    for i, (xi, yi) in enumerate(shares):
        num = yi
        den = 1
        for j, (xj, _) in enumerate(shares):
            if i == j:
                continue
            num = num * (-xj) % prime
            den = den * (xi - xj) % prime
        secret = (secret + num * pow(den, prime - 2, prime)) % prime
    return secret
```

`prime` must be a genuine prime so `pow(den, prime-2, prime)` gives the correct modular inverse (Fermat's little theorem). Pass `_TW_N`, not `_TW_ORDER`.

### Step 3: DKG Round 1 — commitment broadcast

```python
def dkg_round1(party_id: int, n: int, t: int, prime: int) -> tuple[list[int], list[int]]:
    order = prime - 1
    coeffs = [_det_coeff(party_id * 1000 + i, i, order) or 1 for i in range(t)]
    commitments = [pow(_TW_G, c, prime) for c in coeffs]
    return coeffs, commitments
```

Coefficients are scalars (mod ORDER); commitments are group elements (mod N).

### Step 4: DKG Round 2 — share aggregation

```python
def dkg_round2(party_id: int, other_shares: list[tuple[int, int]], prime: int) -> int:
    order = prime - 1
    return sum(s for _, s in other_shares) % order
```

Each party sums the shares it received from every other party (including its own) to get its final secret share.

### Step 5: Group public key

```python
def dkg_final_pubkey(all_commitments: list[list[int]], prime: int) -> int:
    pk = 1
    for party_commitments in all_commitments:
        pk = pk * party_commitments[0] % prime
    return pk
```

### Step 6: Threshold Schnorr — Round 1 (nonce generation)

```python
def threshold_sign_round1(party_id: int, prime: int) -> tuple[int, int]:
    order = prime - 1
    nonce = _det_coeff(party_id, 0, order) or 1
    return nonce, pow(_TW_G, nonce, prime)
```

### Step 7: Threshold Schnorr — Round 2 (partial signature)

```python
def threshold_sign_round2(party_id, sk_share, nonce_secret, agg_nonce, message, prime):
    order = prime - 1
    challenge = _sha256_int(agg_nonce.to_bytes(8, "big") + message) % order
    return (nonce_secret + sk_share * challenge) % order
```

### Step 8: Aggregate and verify

```python
def threshold_aggregate_sigs(partial_sigs: list[int], prime: int) -> int:
    return sum(partial_sigs) % (prime - 1)

def threshold_verify(agg_pk, agg_nonce, message, sig, prime):
    order = prime - 1
    challenge = _sha256_int(agg_nonce.to_bytes(8, "big") + message) % order
    lhs = pow(_TW_G, sig, prime)
    rhs = agg_nonce * pow(agg_pk, challenge, prime) % prime
    return lhs == rhs
```

## Pitfalls

1. **Wrong prime for Lagrange.** Using a non-prime modulus in Shamir reconstruction silently gives wrong answers. `N-1 = 2^31-2` is not prime. Always pass `N` (prime) to `shamir_split` and `shamir_reconstruct`.
2. **Scalar vs group modulus confusion.** Polynomial coefficients and Schnorr scalars live in Z_{N-1} (mod ORDER). Public keys and commitments live in Z_N (mod PRIME). Mixing them corrupts verification.
3. **Nonce reuse in threshold signing.** Reusing any party's nonce `k_i` across two signings exposes that party's secret share, just as nonce reuse in standard Schnorr exposes the private key.
4. **Rogue-key attack in DKG.** A malicious party can choose their commitment to cancel out honest parties' public keys. Production DKG requires proof-of-knowledge of the secret scalar (e.g., a Schnorr proof alongside each commitment).
5. **Below-threshold reconstruction.** Any `t-1` shares reveal zero information about the secret in information-theoretic terms, but the code will still return *some* number. Never interpret a below-threshold reconstruction result as correct.

## Key Terms

| Term | What people say | What it actually means |
|---|---|---|
| Shamir Secret Sharing | "SSS" | Split a secret into n shares so any t reconstruct it, fewer reveal nothing |
| Threshold | "t-of-n" | Minimum number of parties required to reconstruct a secret or produce a signature |
| DKG | "distributed key gen" | Protocol for n parties to jointly generate a shared keypair with no trusted dealer |
| FROST | "threshold Schnorr" | Flexible Round-Optimised Schnorr Threshold — the standard MPC signing protocol |
| Lagrange interpolation | "polynomial reconstruction" | Computing f(0) from t points on a degree-(t-1) polynomial |
| Partial signature | "share sig" | Each party's contribution s_i = k_i + sk_i * e; aggregated into one Schnorr sig |
| Group order | "ORDER" | Number of elements in the multiplicative group; equals N-1 for prime N |
