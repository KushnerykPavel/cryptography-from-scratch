# Rings, Ideals, Quotient Rings

> A ring is a group that learned to multiply; an ideal is the subset stable enough to divide by.

**Type:** Learn
**Languages:** Python
**Prerequisites:** 02-abstract-algebra/01-groups, 02-abstract-algebra/03-subgroups-cosets-lagrange, 02-abstract-algebra/04-homomorphisms
**Time:** ~75 minutes

> ⚠️ Educational implementation. Not constant-time. Not production-safe.

## The Problem

Groups carry one operation. Cryptography wants two.

You need to add scalars *and* multiply them. You need to multiply polynomials *and* add them. You need to take a residue mod `n`, mod `p`, mod an irreducible polynomial, mod a lattice basis. Every one of those moves is the same algebraic gesture: pick a *ring*, pick an *ideal*, and quotient out.

Without the ring/ideal/quotient vocabulary, modular arithmetic is a trick that happens to work for integers, polynomials in `F_p[x]`, Gaussian integers, and ideal lattices in `Z[X]/(X^n + 1)`. With it, they are one construction. Kyber's polynomial ring, RSA's `Z/nZ`, BLS12-381's `F_p[u]/(u^2 + 1)`, and FHE's `Z_q[X]/(X^N + 1)` are all the same recipe applied to different ingredients.

The danger of skipping the vocabulary is that *not every subset is an ideal* and *not every quotient is a ring*. Pick the wrong subset and "reduction" stops being well-defined. Pick a ring with zero divisors and "division" stops being safe. Both errors show up in real protocol bugs.

## The Concept

A **ring** `(R, +, ·)` is a set with two operations such that:

```text
(R, +)               is an abelian group
·                    is associative and closed on R
·                    distributes over +:
                       a · (b + c) = a · b + a · c
                       (b + c) · a = b · a + c · a
```

A **commutative ring** also has `a · b = b · a`. A **ring with unity** has a multiplicative identity `1`. Throughout this lesson the rings are finite, commutative, and unital — like `Z/nZ`.

### Units and zero divisors

In `Z/nZ`:

```text
unit          gcd(a, n) = 1, has a multiplicative inverse
zero divisor  a ≠ 0 and there exists nonzero b with a · b = 0
```

A ring with no nonzero zero divisors is an **integral domain**. A commutative ring where every nonzero element is a unit is a **field**. For `Z/nZ`:

```text
n prime    -> Z/nZ is a field
n composite -> zero divisors exist, not an integral domain
```

The interesting elements of cryptographic rings are usually exactly the units (e.g. RSA private exponent lives in the units of `Z/φ(n)Z`).

### Ideals

An **ideal** `I ⊆ R` is a subset that:

1. contains `0`,
2. is closed under addition,
3. is closed under additive inverses,
4. **absorbs** multiplication by anything in `R`:

```text
for all r in R, for all s in I:    r · s in I    and    s · r in I
```

The absorption rule is what separates ideals from mere subgroups. In `Z/12Z`, the subgroup `{0, 6}` is an ideal because multiplying any ring element by `6` lands back in `{0, 6}`. The subgroup `{0, 1}` is *not* an ideal — `2 · 1 = 2 ∉ {0, 1}`.

### Principal ideals

A **principal ideal** is generated by one element `g`:

```text
(g) = { r · g : r in R }
```

In `Z/12Z`:

```text
(3) = {0, 3, 6, 9}
(4) = {0, 4, 8}
(6) = {0, 6}
```

In `Z`, every ideal is principal — `Z` is a *principal ideal domain*. In `F[x]`, every ideal is principal — that is why `F[x]/(f(x))` is so useful.

### Quotient rings

If `I` is an ideal of `R`, the **quotient ring** `R/I` has:

```text
elements   cosets a + I = { a + s : s in I }
addition   (a + I) + (b + I) = (a + b) + I
multiplication   (a + I) · (b + I) = (a · b) + I
```

Both operations are *well-defined* exactly because `I` is an ideal. If `I` only respected addition (no absorption), multiplication of cosets would depend on which representative you picked.

Three examples:

```text
Z/12Z / (3)  has 3 cosets   {0,3,6,9}, {1,4,7,10}, {2,5,8,11}   ≅ Z/3Z
Z/12Z / (4)  has 4 cosets   ≅ Z/4Z
Z/6Z  / (2)  has 2 cosets   ≅ Z/2Z
```

The pattern: `Z/nZ / (d) ≅ Z/dZ` when `d | n`.

### Quotients you already know

| You wrote | It is really |
|-----------|--------------|
| `a mod n` | `a + nZ` in `Z/nZ = Z/(n)` |
| `(a + b) mod n` | quotient addition in `Z/(n)` |
| `f(x) mod p(x)` | coset of `f(x)` in `F[x]/(p(x))` |
| AES `GF(2^8)` element | coset in `F_2[x]/(x^8 + x^4 + x^3 + x + 1)` |
| Kyber polynomial | element of `Z_q[X]/(X^256 + 1)` |
| Pairing tower `F_p^2` | `F_p[u]/(u^2 - β)` |

Every "reduce mod something" step in cryptography is a quotient ring.

## Build It

This lesson builds a finite-ring inspector:

- check ring axioms
- compute units and zero divisors
- build principal ideals
- validate that a subset is actually an ideal
- enumerate cosets in `R/I`
- verify the quotient is itself a ring

### Step 1: Reuse the finite-group helpers

The ring's additive structure is an abelian group. Reuse the same helpers from the previous lesson:

```python
def add_mod(a: int, b: int, n: int) -> int:
    if n <= 0:
        raise ValueError("modulus must be positive")
    return (a + b) % n


def mul_mod(a: int, b: int, n: int) -> int:
    if n <= 0:
        raise ValueError("modulus must be positive")
    return (a * b) % n


def residues_mod(n: int) -> list[int]:
    if n <= 0:
        raise ValueError("modulus must be positive")
    return list(range(n))
```

`find_identity`, `is_closed`, `is_associative`, `inverse_of`, and `is_commutative` carry over unchanged.

### Step 2: Validate the ring axioms

A ring is an abelian group under addition, closed and associative under multiplication, with distributivity:

```python
def is_distributive(elements, add, mul):
    return all(
        mul(a, add(b, c)) == add(mul(a, b), mul(a, c))
        and mul(add(b, c), a) == add(mul(b, a), mul(c, a))
        for a in elements
        for b in elements
        for c in elements
    )


def is_ring(elements, add, mul):
    if not is_abelian_group(elements, add):
        return False
    if not is_closed(elements, mul):
        return False
    if not is_associative(elements, mul):
        return False
    return is_distributive(elements, add, mul)
```

Exhaustive distributivity is `O(n^3)` — fine for `Z/12Z`, not for real cryptographic rings. The point is to *see* the axioms before trusting them.

### Step 3: Find units and zero divisors

The additive identity (`zero`) always exists in a ring. The multiplicative identity (`one`) might or might not — we ask `find_identity` to look:

```python
def additive_identity(elements, add):
    identity = find_identity(elements, add)
    if identity is None:
        raise ValueError("additive identity does not exist")
    return identity


def multiplicative_identity(elements, mul):
    return find_identity(elements, mul)
```

A **unit** is invertible under multiplication. A **zero divisor** is a nonzero element that kills another nonzero element:

```python
def units(elements, add, mul):
    one = multiplicative_identity(elements, mul)
    if one is None:
        return []
    return sorted(x for x in elements if inverse_of(x, elements, mul) is not None)


def zero_divisors(elements, add, mul):
    zero = additive_identity(elements, add)
    nonzero = [x for x in elements if x != zero]
    divisors = []
    for a in nonzero:
        for b in nonzero:
            if mul(a, b) == zero:
                divisors.append(a)
                break
    return sorted(divisors)
```

For `Z/12Z`:

```text
units         {1, 5, 7, 11}              gcd(a, 12) = 1
zero divisors {2, 3, 4, 6, 8, 9, 10}     gcd(a, 12) > 1, a != 0
```

For `Z/5Z` (a field):

```text
units         {1, 2, 3, 4}
zero divisors {}
```

### Step 4: Build a principal ideal

```python
def principal_ideal(generator, elements, mul):
    if generator not in set(elements):
        raise ValueError("generator must be in the ring")
    return unique_sorted([mul(generator, r) for r in elements])
```

In `Z/12Z`:

```text
(3) -> [0, 3, 6, 9]
(4) -> [0, 4, 8]
(6) -> [0, 6]
```

### Step 5: Check the ideal definition

A subset is an ideal when it is a subgroup of `(R, +)` *and* absorbs multiplication:

```python
def is_ideal(subset, elements, add, mul):
    if not is_ring(elements, add, mul):
        return False

    element_set = set(elements)
    subset_set = set(subset)
    if not subset_set.issubset(element_set):
        return False
    if len(subset_set) != len(subset):
        return False
    if len(subset) == 0:
        return False

    zero = additive_identity(elements, add)
    if zero not in subset_set:
        return False

    for a in subset:
        for b in subset:
            if add(a, b) not in subset_set:
                return False

    for a in subset:
        if inverse_of(a, elements, add) not in subset_set:
            return False

    for r in elements:
        for s in subset:
            if mul(r, s) not in subset_set:
                return False
            if mul(s, r) not in subset_set:
                return False

    return True
```

A common trap: `{0, 1}` in `Z/6Z` is closed under nothing useful. It fails additive closure (`1 + 1 = 2`) and absorption (`2 · 1 = 2`). It is a subset of a ring; it is not an ideal.

### Step 6: Enumerate cosets

A coset of `I` is `a + I = { a + s : s in I }`. For a deterministic listing pick the canonical representative — the smallest element in the coset:

```python
def canonical_coset_rep(element, ideal, add):
    return min(add(element, i) for i in ideal)


def quotient_coset_reps(elements, ideal, add, mul):
    if not is_ideal(ideal, elements, add, mul):
        raise ValueError("subset must be an ideal of the ring")

    reps, seen = [], set()
    for element in elements:
        rep = canonical_coset_rep(element, ideal, add)
        if rep not in seen:
            seen.add(rep)
            reps.append(rep)
    return sorted(reps)
```

For `Z/12Z / (3)`:

```text
reps -> [0, 1, 2]
cosets {0,3,6,9}, {1,4,7,10}, {2,5,8,11}
```

### Step 7: Verify R/I is a ring

Quotient operations act on representatives:

```python
def quotient_add(a, b, elements, ideal, add, mul):
    if not is_ideal(ideal, elements, add, mul):
        raise ValueError("subset must be an ideal of the ring")
    return canonical_coset_rep(add(a, b), ideal, add)


def quotient_mul(a, b, elements, ideal, add, mul):
    if not is_ideal(ideal, elements, add, mul):
        raise ValueError("subset must be an ideal of the ring")
    return canonical_coset_rep(mul(a, b), ideal, add)


def quotient_is_ring(elements, ideal, add, mul):
    reps = quotient_coset_reps(elements, ideal, add, mul)
    qadd = lambda a, b: quotient_add(a, b, elements, ideal, add, mul)
    qmul = lambda a, b: quotient_mul(a, b, elements, ideal, add, mul)
    return is_ring(reps, qadd, qmul)
```

The well-definedness of `quotient_mul` is *exactly* the absorption rule for `I`. Without absorption, picking a different representative would give a different coset.

## Use It

Real cryptographic libraries do not write `is_ring(...)` — they encode the ring as a type:

- `pyca/cryptography` and `RustCrypto/num-bigint` model `Z/nZ` through fixed-modulus integer types.
- `arkworks` models prime fields and field extensions as `FpConfig`-driven structs. Each field is a `F_p[x]/(p(x))` quotient.
- `galois` (Python) exposes `GF(2**8)` as `F_2[x]/(x^8 + x^4 + x^3 + x + 1)` — the AES field.
- Kyber/Dilithium reference code uses an array of coefficients in `Z_q` with explicit reduction modulo `X^256 + 1` — a polynomial quotient ring.

When you use one of these libraries, ask: *what is the ring, and what is the ideal I'm quotienting by?* The performance, the side-channel surface, and the algebraic identities all live there.

## Attack It

This is a Learn lesson, but real failure modes follow directly from the algebra.

```text
Picking n composite for a field-like protocol
  Z/nZ has zero divisors. Algorithms assuming inverses always exist will silently produce wrong values or NaN-style outputs.

Reducing a polynomial mod a reducible f(x)
  F_p[x]/(f) is not a field. Some nonzero polynomials become zero divisors. Multiplicative inverses are not defined for all elements. ECDSA-style "divide by k" operations break.

Treating a subgroup as an ideal
  Coset multiplication is not well-defined. A "quotient" built from a non-ideal subgroup gives different answers for different representatives.

Forgetting noise/error terms live in a coset
  In LWE-style schemes, a ciphertext is "message + error" in some quotient ring. Mistaking the representative for the unique value misses the entire decryption budget.
```

The general lesson: when you "take a remainder", you must know which ring, which ideal, and whether the quotient is a ring (always, given a true ideal), an integral domain (`I` is *prime*), or a field (`I` is *maximal*).

## Key Terms

| Term | What people say | What it actually means |
|------|----------------|----------------------|
| Ring | "Two ops" | Set with `+` (abelian group), `·` (associative), distributive |
| Commutative ring | "Like the integers" | Ring where `a · b = b · a` |
| Unit | "Invertible" | Element `a` with `a · b = 1` for some `b` |
| Zero divisor | "Multiplies to zero" | Nonzero `a` with `a · b = 0` for some nonzero `b` |
| Integral domain | "No zero divisors" | Commutative ring with `1` and no nonzero zero divisors |
| Field | "Everything inverts" | Commutative ring where every nonzero element is a unit |
| Ideal | "Stable subset" | Subgroup of `(R, +)` that absorbs multiplication by `R` |
| Principal ideal | "One generator" | `(g) = { r · g : r in R }` |
| Quotient ring | "Mod the ideal" | `R/I` with cosets as elements; operations descend from `R` |
| Coset | "Equivalence class" | `a + I = { a + s : s in I }` |
