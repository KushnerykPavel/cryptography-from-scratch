# Terms

Glossary of every term used in the course. One line per term where possible. Cite sources for definitions that have multiple in-the-wild meanings.

## Number Theory

| Term | Definition | First lesson |
|------|------------|--------------|
| Modular arithmetic | Arithmetic on Z/nZ — integers mod n | 01/01 |
| GCD | Greatest common divisor; computed via Euclidean algorithm | 01/02 |
| Bezout coefficients | Integers (s, t) such that sa + tb = gcd(a, b) | 01/02 |
| Modular inverse | a^(-1) mod n exists iff gcd(a, n) = 1 | 01/03 |
| Euler's totient φ(n) | Count of integers in [1, n] coprime to n | 01/06 |
| Carmichael λ(n) | Smallest m such that a^m ≡ 1 mod n for all a coprime to n | 01/06 |
| CRT | Chinese Remainder Theorem — solves system of mod equations | 01/05 |
| Quadratic residue | x mod n such that x ≡ y² mod n for some y | 01/07 |
| Legendre symbol (a/p) | +1 / -1 / 0 indicating QR-ness over prime p | 01/08 |
| Jacobi symbol | Multiplicative extension of Legendre to composite n | 01/08 |
| Tonelli-Shanks | Computes square roots mod prime p | 01/07 |
| Miller-Rabin | Probabilistic primality test based on Fermat | 01/10 |
| AKS | Deterministic polynomial-time primality test | 01/11 |
| Pollard rho | Cycle-finding factoring algorithm | 01/12 |
| Quadratic sieve | Sub-exponential factoring algorithm for medium-size n | 01/13 |
| Index calculus | Sub-exponential discrete log algorithm | 01/14 |
| BSGS | Baby-step giant-step — O(√n) DLP algorithm | 01/15 |

## Abstract Algebra

| Term | Definition | First lesson |
|------|------------|--------------|
| Group | Set with associative operation, identity, inverses | 02/01 |
| Cyclic group | Group generated by a single element | 02/02 |
| Subgroup | Subset closed under the group operation | 02/03 |
| Coset | a·H = {a·h : h ∈ H} for subgroup H | 02/03 |
| Lagrange's theorem | |H| divides |G| for finite group G | 02/03 |
| Ring | Set with two ops (+, ·) — abelian under +, monoid under · | 02/05 |
| Ideal | Subring closed under multiplication by ring elements | 02/05 |
| Field | Commutative ring where every non-zero element has a · inverse | 02/06 |
| Finite field GF(p) | Integers mod prime p | 02/07 |
| Finite field GF(2^n) | Polynomial ring F_2[x] / (irreducible f(x)) | 02/08 |
| Cyclotomic polynomial | Φ_n(x) — minimal polynomial of primitive n-th root of unity | 02/11 |
| NTT | Number Theoretic Transform — FFT over finite fields | 02/12 |
